# Content rating (IARC questionnaire)

Play Console → Policy → App content → Content rating → Start questionnaire. Email: your contact address.
Category: **Utility, Productivity, Communication, or Other** (not "Social/Communication" unless Play pushes you there; the
app has no messaging between users).

| Question | Answer |
| --- | --- |
| Violence (any kind) | No |
| Blood / gore | No |
| Sexuality / nudity | No |
| Profanity / crude humor | No |
| Controlled substances (drugs, alcohol, tobacco depicted/promoted) | No |
| Gambling / simulated gambling | No |
| Horror / fear | No |
| Discrimination / hate | No |
| Does the app allow users to interact or exchange content with each other? | No (the app has no accounts or chat; contact with sellers happens on kleinanzeigen.de, outside the app) |
| Does the app share the user's location with other users? | No |
| Does the app allow users to purchase digital goods? | No |
| Does the app contain / link to unrestricted web access? | No (links open kleinanzeigen.de listings in the external browser; no general browser) |
| User-generated content? | No (private notes are visible only to the user) |

Caveat to answer honestly: the app displays third-party classified listings from kleinanzeigen.de. These are not
curated by the developer; Kleinanzeigen prohibits illegal/adult content in its own terms. If the questionnaire asks about
"user-generated content shown from a third-party service", answer **Yes, third-party content, moderated by the third party**
and expect a rating like **USK 0 / PEGI 3 / ESRB Everyone, possibly "Users Interact: No" / "Shares Location: No"**.

Target audience: **18+** is the safest choice (marketplace content, not designed for children). Do **not** pick an age
group under 13 – that triggers the Families policy. News app: No. Government app: No.
